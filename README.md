# MIT 6.006: Introduction to Algorithms (C++ Port)

This repository contains complete C++ translations of the algorithms and data structures taught in [MIT OCW 6.006: Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/). 

While the original course materials and recitations are taught using Python, this project ports the codebase to modern C++ to explore the algorithms with strict type safety, manual memory management, and lower-level performance characteristics. 

**Topics Covered:**
* Sorting and Trees (Insertion Sort, Merge Sort, AVL Trees)
* Hashing (Hash Tables, Karp-Rabin)
* Graph Algorithms (BFS, DFS, Dijkstra, Bellman-Ford)
* Dynamic Programming
